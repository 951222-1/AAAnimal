# 動物幾隻腳｜體感訓練版

給長輩玩的 webcam 體感遊戲：看動物題目，透過坐姿、站姿、單腳平衡或雙手舉高來回答。

## 執行

```bash
npm install
npm run dev
```

開啟終端顯示的本機網址（預設 `http://127.0.0.1:5173/`）。進入遊戲後按「開啟鏡頭」並允許相機權限；若暫時不使用鏡頭，可選「沒有鏡頭？按鈕試玩」。

## 遊戲模式

- 自在訓練：不限時，0、1、2、4 隻腳姿勢練習。
- 簡單挑戰：40 秒，每題 8 秒，0／2／4 隻腳。
- 一般挑戰：30 秒，每題 5 秒，0／1／2／4 隻腳。
- 困難挑戰：30 秒，穿插簡易加減法。
- 雙人搶快 PK：兩位玩家各自回答，答對有基礎分，先答對另有加分。
- 雙人合作：45 秒、每題 6 秒，兩人合計湊出 0～8 隻腳。

題目不會連續出現相同腳數。單人姿勢需維持 0.4 秒；合作合計姿勢需維持 0.5 秒。

## 姿勢辨識與資產

使用 MediaPipe Pose Landmarker，模型與 WASM 資產置於 `public/models/` 與 `public/wasm/`，瀏覽器啟動時不需另外下載模型。坐姿優先於手腳判定；站姿下以雙手高於肩膀判為 4、單腳踝抬高判為 1、雙手低於肩膀判為 2。

目前判定門檻是初版，應在實際攝影機、不同身形與取景距離下再調整。單腳練習請在穩固椅旁進行，以安全舒適為優先。

## 測試與建置

```bash
npm test
npm run build
```

姿勢分類與穩定維持判定測試位於 `tests/`。自動測試不取代真人攝影機實測；真人鏡頭辨識仍需在允許相機後驗證。
